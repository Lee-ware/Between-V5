BRAIN

This is where BETWEEN stops asking, “What do you think?” and starts saying:

> “Okay. Let's see how quickly you can actually do it.”



I deliberately built this as a mini-game lab, not “trivia but faster.”

The mechanics are inspired by established task formats such as visual change detection, sequence recall, spatial memory, go/no-go inhibition, and task switching. These are useful game mechanics, but BETWEEN should not claim that its scores measure intelligence or improve someone's brain. Research shows these tasks can measure specific performance dimensions, while broad “brain training makes you smarter” claims are much harder to justify.

BRAIN 01 — CODE BREAKER

The idea

A visual grid contains symbols.

One symbol is the target.

The player must find it as quickly as possible.

Example

┌───┬───┬───┬───┐
│ ▲ │ ● │ ■ │ ◆ │
├───┼───┼───┼───┤
│ ◆ │ ▲ │ ● │ ■ │
├───┼───┼───┼───┤
│ ■ │ ◆ │ ▲ │ ● │
├───┼───┼───┼───┤
│ ● │ ■ │ ◆ │ ▲ │
└───┴───┴───┴───┘

TARGET: ◆

Tap it.

Difficulty

Level 1 → 3×3
Level 2 → 4×4
Level 3 → 5×5
Level 4 → 6×6
Level 5 → one decoy looks almost identical

Score

score = accuracy × speed multiplier

Wrong tap = penalty.

BRAIN 05 — RULE SWITCH

This is one of the most important games in the mode.

The player sees a symbol.

The rule changes.

Round 1

Tap BLUE

🔵 → TAP
🔴 → DON'T
🟢 → DON'T

Then suddenly:

Round 2

Tap RED

🔵 → DON'T
🔴 → TAP
🟢 → DON'T

Then:

Round 3

Tap GREEN

Then:

Round 4

Tap anything EXCEPT blue

Then:

Round 5

Tap the opposite of the previous rule

The player has to continuously update the rule instead of simply repeating a learned response.

Task-switching research specifically studies the cost of changing between rules/tasks and resolving competing response demands.

BRAIN SCORING

Do not make one giant number called:

> “Your IQ: 127”



Absolutely not.

Instead:

BRAIN RUN

Accuracy      87%
Speed         74%
Memory        81%
Switching     69%
Consistency   92%

Then:

> Your strongest run: Memory



or:

> You were fast. Your accuracy wasn't impressed.



Or:

> You survived 8 rule changes before your brain filed a complaint.



These are game stats, not psychological assessments.

Research on visual working memory supports the idea that performance can vary with load and task demands; it does not justify turning a casual game score into a general intelligence diagnosis.

BRAIN DIFFICULTY SYSTEM

Don't simply make everything faster.

Increase difficulty through different dimensions:

MEMORY
3 items → 4 → 5 → 6 → 7

SPEED
1500ms → 1200 → 900 → 700 → 500

DISTRACTION
none → minor → similar → misleading

RULES
1 → 2 → switching → conflicting

VISUAL LOAD
3×3 → 4×4 → 5×5 → 6×6

SEQUENCE
4 → 5 → 6 → 7 → 8

COMBINATION
one mechanic → two → three

That gives BETWEEN a huge amount of replayability without needing thousands of hand-written questions.

THE BRAIN CONTENT FORMAT

For the eventual data structure, each game can follow something like:

{
  id: "brain-code-001",
  type: "code",
  difficulty: 2,
  duration: 45,
  mechanic: "symbol_mapping",
  rounds: [...]
}

And a round can contain:

{
  prompt: "...",
  data: [...],
  answer: "...",
  timeLimit: 3000
}

The engine generates variations rather than requiring you to manually create every single round.

That is important.

For example, you don't need 500 manually written Memory Grid questions. The system can randomly generate valid grids while controlling:

gridSize
numberOfTargets
displayTime
delay
difficulty
seed

That gives you practically unlimited rounds from a relatively small amount of content.

THE MOST IMPORTANT RULE

BRAIN should never say:

> “Train your brain and become smarter.”



It should say things like:

> “How long can you stay locked in?”



> “Your memory is about to get tested.”



> “Okay. That rule just changed.”



> “You were given one job.”



> “That was unnecessarily difficult.”



> “Again?”



That keeps it fun instead of making unsupported cognitive-enhancement promises.

And because the mechanics themselves can generate new valid rounds, Brain becomes the one BETWEEN mode that can effectively have infinite content rather than needing an enormous question database.
