# BETWEEN v4.0.1 — Sound + flow polish

- Reworked Web Audio into short, distinct tactile sounds for tap, correct, wrong, and reveal feedback.
- Increased sound audibility slightly while keeping effects deliberately subtle; no background music.
- Sound setting now plays one tiny preview when switched ON, so the setting is immediately understandable.
- Pick One is now frictionless: choosing an option records the answer and automatically advances; removed the redundant “Locked in” reveal and Next button.
- Kept explicit result/reveal steps for interactions where the result itself carries useful information (e.g. Knowledge and Estimation).
- PWA manifest and installed-app icon remain unchanged: the BETWEEN mark is the app icon.
